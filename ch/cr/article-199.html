CSS Grid完全指南：二維佈局終極方案

CaesarTools 技術文章 · 2026-10-15

一、Grid和Flexbox的關係

Flexbox一維，處理一行或一列。Grid二維，同時控制行和列。後台骨架：左邊欄右邊內容，頂部底部固定，這種行列交叉佈局用Grid最直觀。

二、基本用法

.grid {

display: grid;

grid-template-columns: 200px 1fr 150px;

grid-template-rows: 60px 1fr 80px;

gap: 16px;

}

三列三行。fr分配剩餘空間。

三、repeat和minmax

repeat(3, 1fr)三列等寬。

minmax(200px, 1fr)最小200px最大平分。

響應式卡片牆：

grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));

不用媒體查詢自動換行。

四、命名區域

grid-template-areas:

"header header header"

"sidebar main main"

"footer footer footer";

改佈局只改模板字符串，HTML不動。

五、子元素定位

grid-column: 1/3跨兩列。

grid-row: 1/span 2跨兩行。

六、對齊

justify-content整個網格對齊。

align-content垂直對齊。

justify-items單元格內容水平。

align-items單元格內容垂直。

七、常見坑

坑1：不寫grid-template-rows，中間區不撐滿。

坑2：圖片溢出單元格。max-width:100%。

坑3：Grid做簡單一行排列大材小用。用Flexbox。

八、auto-fill和auto-fit

auto-fill保留空軌道，auto-fit收縮空軌道。卡片數量少時auto-fit讓少數卡片撐滿，視覺更好。

九、總結

Grid二維佈局。頁面骨架用Grid，組件排列用Flexbox。兩者配合是現代佈局標配。
