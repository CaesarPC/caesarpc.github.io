前端錯誤監控實戰（33）

CaesarTools 技術文章 · 2026-10-15

一、前端為什麼要監控

你不知道用戶那邊出了什麼錯。用戶說"網頁點不了"，你看自己電腦好好的。前端錯誤監控把線上錯誤收集起來，帶堆棧、用戶操作、瀏覽器信息。

二、採集哪些錯誤

JS運行時錯誤：window.onerror

未處理Promise：unhandledrejection

資源加載錯誤：error事件

接口錯誤：攔截fetch

三、上報到後端

window.onerror = (msg, url, line, col, error) => {

fetch('/log', {

method: 'POST',

body: JSON.stringify({ msg, url, line, stack: error?.stack })

});

};

四、Source Map

壓縮後代碼變量名變了，堆棧看不懂。Source Map映射回源碼。生產要上傳Source Map到監控平臺。

五、常見監控服務

Sentry開源免費。阿里雲ARMS。騰訊前端監控。

六、常見坑

上報本身失敗不要影響業務。採樣上報，不用全量。Source Map不要公開暴露。

七、總結

前端錯誤監控把線上問題帶回開發電腦。Sentry開箱即用。
