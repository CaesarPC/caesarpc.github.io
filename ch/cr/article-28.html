CSS佈局模式大全：從聖盃到Grid的演進

一、CSS佈局為什麼這麼難

早年做個三欄佈局，要float、清浮動、margin負值、hack。現在有Flexbox和Grid，幾行代碼搞定。但很多老代碼還是float佈局，新工程師看不懂。這篇梳理所有經典佈局模式。

二、居中佈局

2.1 Flexbox居中

.container { display:flex; justify-content:center; align-items:center; }

最簡單的垂直水平居中。

2.2 Grid居中

.container { display:grid; place-items:center; }

更簡潔，一行代碼。

2.3 絕對定位+transform

.child { position:absolute; top:50%; left:50%; transform:translate(-50%,-50%); }

老瀏覽器兼容方案。

三、三欄佈局

3.1 Flexbox三欄

.container { display:flex; }

.left { width:200px; }

.right { width:150px; }

.main { flex:1; }

左右固定，中間自適應。

3.2 Grid三欄

.container { display:grid; grid-template-columns:200px 1fr 150px; }

更直觀。

3.3 聖盃佈局

float + padding + 負margin的老方案。現在沒人用了，面試可能問。

四、等高分欄

Flexbox默認align-items:stretch，子元素高度自動等高。不用額外處理。

Grid同理，同一行的單元格等高。

五、 sticky footer

內容不夠長時footer貼底，內容長了footer隨內容走。

Flexbox方案：body { display:flex; flex-direction:column; min-height:100vh; } main { flex:1; }

六、側邊欄+主內容

Grid方案：

.layout {

display:grid;

grid-template-columns:240px 1fr;

grid-template-rows:60px 1fr 40px;

grid-template-areas:

"header header"

"sidebar main"

"footer footer";

min-height:100vh;

}

後台管理系統標準佈局。

七、響應式佈局

7.1 移動優先

先寫手機樣式，再用min-width媒體查詢增強。

@media (min-width:768px) { ... }

7.2 Grid自適應卡片

.card-list {

display:grid;

grid-template-columns:repeat(auto-fill, minmax(220px,1fr));

gap:20px;

}

不用寫媒體查詢，自動響應。

八、常見坑

坑1：float清除不乾淨。現代用Flex/Grid。

坑2：margin重疊。BFC隔離。

坑3：垂直居中用line-height。多行文字失效。

坑4：絕對定位元素撐開父容器。父容器要overflow:hidden。

九、垂直居中的歷史

早年垂直居中是前端面試必考。方案：table-cell、絕對定位+margin:auto、負margin、transform。現在Flexbox三行代碼解決。面試還問是因為老代碼裡還有這些hack。

十、總結

CSS佈局從float hack演進到Flexbox一維、Grid二維。新項目無腦Grid做骨架、Flex做組件。老代碼看到float不要慌，知道歷史就行。
