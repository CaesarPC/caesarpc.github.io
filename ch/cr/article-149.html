JavaScript防抖與節流（5）

CaesarTools 技術文章 · 2026-10-15

一、為什麼需要防抖節流

輸入框每次按鍵都發請求，瘋狂打後端。滾動事件每幀觸發，主線程忙。防抖節流控制觸發頻率。

二、防抖debounce

等最後一次觸發後再執行。輸入框搜索用：

function debounce(fn, delay) {

let timer;

return (...args) => {

clearTimeout(timer);

timer = setTimeout(() => fn(...args), delay);

};

}

const onSearch = debounce(search, 300);

三、節流throttle

固定時間間隔執行一次。滾動用：

function throttle(fn, interval) {

let last = 0;

return (...args) => {

const now = Date.now();

if (now - last >= interval) {

last = now;

fn(...args);

}

};

}

四、對比

防抖：停止輸入後執行一次。

節流：每300毫秒執行一次。

五、常見場景

輸入搜索：防抖。

滾動加載：節流。

窗口resize：防抖。

六、總結

防抖節流控制事件頻率。防抖等最後一次，節流固定間隔。
