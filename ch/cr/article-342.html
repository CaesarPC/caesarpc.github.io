Docker容器化部署實戰

CaesarTools 技術文章 · 2026-10-15

一、Docker解決什麼

開發Mac、測試Windows、生產Linux。環境不一致bug修不完。Docker把應用和依賴打包成鏡像，任何機器跑起來一樣。

二、Dockerfile

FROM node:20-alpine

WORKDIR /app

COPY package*.json ./

RUN npm ci --production

COPY . .

EXPOSE 3000

CMD ["node", "app.js"]

三、層緩存

先COPY package.json再npm ci。依賴沒變就用緩存。

四、多階段構建

前端構建產物不需要Node：

FROM node:20-alpine AS builder

COPY . .

RUN npm ci && npm run build

FROM nginx:alpine

COPY --from=builder /app/dist /usr/share/nginx/html

最終鏡像50MB。

五、docker-compose

services:

api:

build: .

db:

image: postgres:16

docker-compose up -d。

六、生產要點

不要root跑容器。

鏡像打版本標籤。

日誌輸出stdout。

健康檢查。

資源限制。

七、常見坑

容器監聽127.0.0.1外部訪問不到，要0.0.0.0。

容器重建數據丟，數據庫掛volume。

鏡像大，用alpine和多階段。

八、CI/CD裡用Docker

push代碼→CI構建鏡像→推到Registry→生產pull重啟。全自動發佈，環境一致。

九、總結

Docker是現代部署標配。寫好Dockerfile、層緩存、多階段、compose管理多服務。
