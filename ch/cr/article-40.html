Redis緩存實戰

CaesarTools 技術文章 · 2026-10-15

一、Redis是什麼

數據放內存，讀0.1毫秒。單線程，單機每秒10萬讀寫。最常見用法是緩存熱點數據。

二、基本用法

const redis = require('redis');

const client = redis.createClient();

await client.connect();

await client.setex('article:list', 10, JSON.stringify(articles));

const cached = await client.get('article:list');

三、緩存流程

先查緩存，沒有查數據庫，查完寫回。

四、三大問題

穿透：查不存在的key。緩存空結果或布隆過濾器。

擊穿：熱點key過期。互斥鎖或不過期。

雪崩：大量key同時過期。TTL加隨機偏移。

五、更新策略

先更新數據庫，再刪緩存。不要先更新緩存。

六、其他用途

排行榜ZSet。分佈式鎖SET NX。消息隊列List/Stream。

七、常見坑

大key拆分。

沒TTL內存爆。

公網暴露開密碼。

當數據庫用，緩存要能從數據庫重建。

八、生產部署

開密碼、綁內網、RDB+AOF持久化、內存滿allkeys-lru。主從+哨兵高可用。

九、緩存和數據庫一致性

Cache-Aside模式：讀時緩存miss再查庫回寫，寫時先更新庫再刪緩存。極端情況有不一致窗口，要求高用延遲雙刪。

十、總結

Redis緩存熱點數據抗壓力。處理穿透、擊穿、雪崩。生產開密碼、持久化、主從高可用。
