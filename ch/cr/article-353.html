TypeScript入門到實戰

CaesarTools 技術文章 · 2026-10-15

一、JS的痛

動態類型運行時才發現錯。大型項目改字段名編譯不報錯，用戶點擊才崩。TS加靜態類型，編譯時抓錯。

二、基本類型

let name: string = '小明';

let age: number = 18;

let hobbies: string[] = ['籃球'];

三、接口

interface User {

id: number;

name: string;

email?: string;

readonly createdAt: Date;

}

傳錯字段編譯報錯。

四、聯合類型

type Status = 'pending' | 'success' | 'error';

比string精確。

五、泛型

function identity(arg: T): T { return arg; }

寫通用函數不丟類型。

六、React裡用

interface Props { title: string; onClick: () => void; }

function Button({ title, onClick }: Props) { ... }

七、常見坑

any等於沒寫。開strict。

as強行斷言出運行時錯。

第三方庫裝@types/xxx。

八、類型推導

TS自動推導，不用每個都標註。邊界（函數參數、公共API）標註就行。

九、Utility Types

Partial讓所有屬性可選。Pick選部分屬性。Omit排除屬性。ReturnType取函數返回類型。這些工具類型讓類型操作更簡潔。

十、總結

TS是JS加類型。大型項目編譯期抓bug，重構有提示。新項目無腦TS。
