瀏覽器存儲：localStorage和IndexedDB

CaesarTools 技術文章 · 2026-10-15

一、瀏覽器能存什麼

Cookie：4KB，每次請求自動帶，適合存會話ID。

localStorage：5MB，永久存，只在前端讀。

sessionStorage：標籤頁關閉就沒。

IndexedDB：幾百MB，結構化數據，異步API。

二、localStorage用法

localStorage.setItem('user', JSON.stringify(user));

const user = JSON.parse(localStorage.getItem('user'));

localStorage.removeItem('user');

同步API，存大數據會卡主線程。5MB夠存用戶設置。

三、IndexedDB

localStorage只能存字符串，5MB。IndexedDB能存結構化數據，幾百MB，異步。

const db = await idb.openDB('myapp', 1, {

upgrade(db) {

db.createObjectStore('notes', { keyPath: 'id' });

}

});

await db.put('notes', { id: 1, text: '筆記內容' });

const note = await db.get('notes', 1);

四、什麼時候用哪個

存用戶設置、token：localStorage。

存大文件、大量筆記：IndexedDB。

存會話標識：Cookie。

五、常見坑

localStorage存JSON要stringify。

localStorage滿了拋異常，要try catch。

隱私模式下localStorage不可用。

六、安全

localStorage裡存敏感信息（密碼、身份證），XSS攻擊能偷到。重要信息用HttpOnly Cookie。

七、總結

瀏覽器存儲選對工具。小數據localStorage，大數據IndexedDB，會話Cookie。
