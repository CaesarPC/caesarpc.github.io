JavaScript事件委託：利用冒泡減少監聽器數量

列表有100個按鈕，每個都綁點擊事件性能差。事件委託利用事件冒泡，在父元素上綁一個監聽器，通過event.target判斷是哪個子元素被點擊。這樣只需要一個監聽器，而不是100個。

原理：事件觸發後會從目標元素冒泡到父元素。在父元素上監聽click，通過event.target找到實際點擊的元素。新增的子元素自動享受委託，不需要重新綁定。

優勢：減少監聽器數量（性能好）；動態添加的元素自動綁定（不需要重新bind）；內存佔用低。

實現：父元素.addEventListener('click', e => { if (e.target.matches('.item')) { ... } })。用matches判斷點擊的是不是目標元素。這是前端優化的常用技巧。
