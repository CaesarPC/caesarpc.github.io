Vite前端構建工具詳解（2）

CaesarTools 技術文章 · 2026-10-15

一、Webpack為什麼慢

中型項目冷啟動30秒，改一行等5秒。Webpack啟動時遞歸打包所有模塊，不管你用不用。

Vite利用瀏覽器原生ESM和esbuild，啟動300毫秒。

二、Vite為什麼快

開發時不打包。瀏覽器請求哪個文件才處理哪個。項目從100模塊變10000，啟動時間不變。

esbuild預構建依賴，比JS打包器快10-100倍。

改一個文件只重新請求那個模塊，毫秒級HMR。

三、基本使用

npm create vite@latest my-app -- --template react

cd my-app && npm install && npm run dev

四、生產構建

npm run build用Rollup。代碼壓縮、tree-shaking、分包。

五、常用配置

server.proxy開發代理。

build.rollupOptions.output.manualChunks分包。

import.meta.env.VITE_xxx環境變量。

六、插件生態

@vitejs/plugin-react、plugin-vue。社區插件豐富。

七、常見坑

IE不支持ESM用legacy插件。

老項目遷移成本高。

某些Webpack loader要換Vite插件。

八、Vite和Webpack怎麼選

新項目Vite。老項目Webpack遷移成本高，逐步遷。需要兼容IE11用Webpack或Vite legacy插件。

九、總結

Vite用瀏覽器原生能力重新定義開發體驗。啟動快、HMR快、配置簡單。新項目無腦選。
