JSON格式化是什麼？為什麼程序員都需要它

概述

CaesarTools · 技術教程

你有沒有見過這樣一堆擠在一起的數據：{"name":"小明","age":18,"city":"深圳"}？

這就是 JSON。它是網頁和服務器之間交換數據最常用的格式。

API 返回的 JSON 數據經常擠成一團，沒有換行沒有縮進，人眼根本看不懂哪裡是哪裡。格式化工具就是把這一團數據變成有縮進、有換行的整齊格式，讓你一眼就能看清結構。

1. 快速看清數據結構，找字段不用翻來翻去

2. 檢查 JSON 有沒有語法錯誤（少個括號、多個逗號）

3. 調試接口的時候，快速定位哪個字段出了問題

本站的實用工具裡就有 JSON 格式化功能，粘貼進去一鍵美化，純本地處理不上傳服務器。
