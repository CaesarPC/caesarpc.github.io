# 前端Fetch API：現代網絡請求

XMLHttpRequest是老派的AJAX方式，寫起來回調嵌套。現代前端用Fetch API——Promise風格，簡潔優雅。

## 一、基本用法

fetch('/api/users') .then(res => res.json()) .then(data => console.log(data)) .catch(err => console.error(err));

async/await寫法更舒服： async function getUsers() { const res = await fetch('/api/users'); const data = await res.json(); return data; }

## 二、POST請求

fetch('/api/users', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: '張三' }) });

## 三、常見坑

fetch不會因為4xx/5xx就reject——只有網絡錯誤才reject。HTTP錯誤狀態碼要手動檢查： if (!res.ok) throw new Error('HTTP ' + res.status);

超時：fetch默認沒有超時。要超時用AbortController： const controller = new AbortController(); setTimeout(() => controller.abort(), 5000); fetch(url, { signal: controller.signal });

## 四、總結

Fetch是現代前端請求數據的標準方式。比XHR簡潔，支持Promise和async/await。記住兩個坑：HTTP錯誤要手動檢查ok，超時要用AbortController。
