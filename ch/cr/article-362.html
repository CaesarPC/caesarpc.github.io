HTTPS證書申請實戰（24）

CaesarTools 技術文章 · 2026-10-15

一、HTTPS為什麼必須上

HTTP明文傳輸，密碼被中間人看。2024年所有現代網站都上HTTPS。

二、Let's Encrypt免費證書

sudo certbot --nginx -d example.com -d www.example.com

Certbot自動申請證書、自動配置Nginx、自動續期。

三、證書有效期

Let's Encrypt證書90天有效期。Certbot自動續期，不用人管。

四、Nginx配置

server {

listen 443 ssl;

ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;

ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

}

五、HTTP跳轉HTTPS

server {

listen 80;

return 301 https://$host$request_uri;

}

六、常見坑

域名解析要先配好。

80端口要開放。

證書要包含所有子域名。

七、總結

Let's Encrypt免費證書，Certbot一鍵配置。HTTPS是網站標配。
