PostgreSQL實戰

CaesarTools 技術文章 · 2026-10-15

一、為什麼選PostgreSQL

MySQL市佔率高，PostgreSQL功能強。2024年新項目多選PostgreSQL：JSONB、全文搜索、PostGIS、pgvector，一個頂好幾個。

二、建表規範

CREATE TABLE users (

id BIGSERIAL PRIMARY KEY,

email VARCHAR(255) UNIQUE NOT NULL,

name VARCHAR(100) NOT NULL,

created_at TIMESTAMPTZ DEFAULT NOW()

);

主鍵BIGSERIAL。時間TIMESTAMPTZ帶時區。該加UNIQUE加UNIQUE。

三、索引

CREATE INDEX idx_users_email ON users(email);

WHERE、JOIN、ORDER BY加索引。小表不加。LIKE '%xx'用不到。

四、JSONB

CREATE TABLE posts (data JSONB);

SELECT * FROM posts WHERE data->>'title' = '第一篇';

GIN索引加速。

五、事務

BEGIN;

UPDATE accounts SET balance=balance-100 WHERE id=1;

UPDATE accounts SET balance=balance+100 WHERE id=2;

COMMIT;

六、連接池

const pool = new Pool({ max: 20 });

不要每次請求new Client。

七、備份

pg_dump dbname > backup.sql。每天定時。主從複製高可用。

八、慢查詢

EXPLAIN ANALYZE看執行計劃。加索引、SELECT只拿需要列、大表分頁用WHERE id > last_id。

九、常見坑

SELECT *只查需要字段。

N+1查詢用JOIN。

忘了WHERE就UPDATE。

十、PostgreSQL擴展

PostGIS地理空間查詢。pgvector向量檢索做AI語義搜索。pg_trgm模糊搜索。一個數據庫覆蓋多種場景。

十一、總結

PostgreSQL是通用數據庫最優解。建表規範加索引、用好事務、連接池、定期備份。
