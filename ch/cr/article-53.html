CSS Grid完全指南

CaesarTools 技術文章 · 2026-10-15

一、Grid和Flexbox關係

Flexbox一維，Grid二維。後台骨架行列交叉用Grid最直觀。

二、基本用法

.grid {

display:grid;

grid-template-columns:200px 1fr 150px;

grid-template-rows:60px 1fr 80px;

gap:16px;

}

三列三行，fr分配剩餘空間。

三、repeat和minmax

repeat(3, 1fr)三列等寬。

minmax(200px, 1fr)最小200px最大平分。

響應式卡片牆：repeat(auto-fill, minmax(220px,1fr))。

四、命名區域

grid-template-areas:

"header header header"

"sidebar main main"

"footer footer footer";

改佈局只改模板。

五、子元素定位

grid-column:1/3跨兩列。

grid-row:1/span 2跨兩行。

六、對齊

justify-content整個網格對齊。

align-content垂直對齊。

justify-items單元格內容水平。

align-items單元格內容垂直。

七、常見坑

不寫grid-template-rows中間不撐滿。

圖片溢出max-width:100%。

Grid做簡單一行用Flexbox。

八、auto-fill和auto-fit

auto-fill保留空軌道。auto-fit收縮空軌道。卡片少用auto-fit撐滿。

九、Grid和Flexbox怎麼選

一行一列排列用Flexbox。行列交叉整體佈局用Grid。實際配合：Grid做頁面骨架，Flex做組件內部排列。

十、總結

Grid二維佈局。頁面骨架Grid，組件排列Flex。配合是現代標配。
