JavaScript數組方法速查與實戰

CaesarTools 技術文章 · 2026-10-15

一、為什麼數組方法重要

數組是JS裡最常用的數據結構。寫業務就是處理數據：列表渲染、篩選、排序、統計。掌握數組方法，代碼從for循環變成聲明式，可讀性翻倍。

二、遍歷方法

2.1 map

map遍歷返回新數組，每個元素加工一次。

const doubled = [1,2,3].map(x => x*2); // [2,4,6]

渲染列表：list.map(item =>

{item.name}
)。

2.2 forEach

遍歷但不返回新數組。副作用操作用：

arr.forEach(item => console.log(item));

要返回值用map，不要用forEach硬湊。

三、篩選和查找

3.1 filter

過濾出符合條件的元素：

const adults = users.filter(u => u.age >= 18);

3.2 find

找第一個符合的元素，找不到返回undefined。

const user = users.find(u => u.id === 1);

3.3 some和every

some：有一個符合就true。

every：全部符合才true。

const hasAdmin = users.some(u => u.role === 'admin');

四、歸約

reduce把數組歸約成一個值：

const sum = [1,2,3].reduce((acc, x) => acc + x, 0); // 6

統計、分組、扁平化都能寫。

五、判斷和包含

includes：arr.includes(3)。

indexOf：找不到返回-1。

findIndex：找索引。

六、排序和反轉

sort默認按字符串排數字要小心：

[1,10,2].sort((a,b) => a-b); // [1,2,10]

reverse反轉。

七、變形

flat展平嵌套數組：[1,[2,[3]]].flat(2); // [1,2,3]

flatMap map後flat一層。

八、常見坑

坑1：map裡寫if不return，得到undefined。

坑2：sort沒傳比較函數，數字排序錯。

坑3：for循環裡異步，順序亂。用for await。

九、鏈式調用

數組方法都返回新數組，可以鏈式：

const result = users

.filter(u => u.age >= 18)

.map(u => u.name)

.sort();

一行一行讀，從左到右數據流。

十、總結

map加工、filter篩選、find查找、reduce歸約、some/every判斷。掌握這幾個，數組業務代碼90%搞定。
