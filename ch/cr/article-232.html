Node.js後端開發：從零寫一個生產級API

CaesarTools 技術文章 · 2026-10-15

一、Node.js是什麼

Chrome V8引擎套事件循環，讓JS跑在服務器上。單線程非阻塞I/O。適合I/O密集：API服務、實時應用。CPU密集不適合。

二、最小服務

const http = require('http');

http.createServer((req, res) => res.end('Hello')).listen(3000);

三行代碼一個服務。實際用Express。

三、Express入門

npm install express

const app = express();

app.use(express.json());

app.get('/api/users', (req, res) => {

res.json([{ id: 1, name: '小明' }]);

});

app.post('/api/users', (req, res) => {

res.status(201).json(req.body);

});

app.listen(3000);

四、路由拆分

routes/users.js：

const router = express.Router();

router.get('/', listUsers);

module.exports = router;

app.use('/api/users', require('./routes/users'));

五、錯誤處理

app.use((err, req, res, next) => {

res.status(500).json({ error: err.message });

});

六、連數據庫

const { Pool } = require('pg');

const pool = new Pool({ connectionString: process.env.DATABASE_URL });

app.get('/api/users', async (req, res, next) => {

try {

const { rows } = await pool.query('SELECT * FROM users');

res.json(rows);

} catch (e) { next(e); }

});

參數化查詢防注入。

七、JWT鑑權

function auth(req, res, next) {

const token = req.headers.authorization?.split(' ')[1];

try {

req.user = jwt.verify(token, process.env.JWT_SECRET);

next();

} catch { res.status(401).json({ error: '未登錄' }); }

}

app.use('/api/protected', auth);

八、部署

PM2進程守護。Nginx反向代理。Docker打包。

九、常見坑

坑1：同步操作阻塞事件循環。CPU密集放Worker。

坑2：沒處理unhandledRejection，進程崩。

坑3：CORS跨域。用cors中間件。

十、Node.js和其他後端

Node.js適合I/O密集、實時應用。Java適合大型企業系統。Python適合數據科學。Go適合高併發基礎設施。選擇看場景，不是選語言選信仰。

十一、總結

Node.js讓前端工程師寫後端API。Express是最穩框架。配合PostgreSQL、Redis、PM2、Nginx，一套完整後端棧。
