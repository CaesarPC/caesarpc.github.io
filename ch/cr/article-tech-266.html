# 什麼是JAMstack：前端現代架構

JAMstack = JavaScript + APIs + Markup。一種現代Web架構：前端是預渲染的靜態HTML，動態數據通過API從後端獲取。

## 一、核心思想

沒有傳統的Web服務器端渲染。網站構建時生成靜態HTML/CSS/JS，部署到CDN上。需要動態數據時，前端JS調用API（數據庫服務、第三方接口）獲取。

## 二、好處

快：靜態文件CDN分發，毫秒級加載。 安全：沒有動態服務器被攻擊的風險。 便宜：靜態託管幾乎免費。 擴展容易：CDN自動處理流量，不用管服務器。

## 三、代價

純靜態的限制：用戶專屬內容、實時數據需要走API。複雜的動態頁面不如傳統SSR靈活。

## 四、總結

JAMstack適合內容站、文檔、營銷頁、工具站。靜態文件+API，快且安全。複雜動態應用還是傳統全棧更合適。
