WebGL與Three.js 3D網頁入門

CaesarTools 技術文章 · 2026-10-15

一、網頁3D是什麼

以前做3D網頁要寫OpenGL Shader，難倒一堆前端。Three.js把底層WebGL封裝了，用JavaScript寫3D網頁變得像寫HTML一樣簡單。現在產品展示、數據大屏、虛擬展廳、3D小遊戲都能做。

三、核心概念

場景Scene：所有物體都放在裡面。

相機Camera：決定從哪個角度看。

渲染器Renderer：把場景畫到畫布上。

幾何體Geometry：物體的形狀，盒子、球、圓柱。

材質Material：物體表面的顏色、反光。

光源Light：沒有光就是黑的。環境光、平行光、點光源。

四、加載3D模型

設計師在Blender裡做好模型，導出.glb文件：

import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loader = new GLTFLoader();

loader.load('model.glb', (gltf) => {

scene.add(gltf.scene);

});

五、交互

OrbitControls讓鼠標拖動旋轉視角：

import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const controls = new OrbitControls(camera, renderer.domElement);

Raycaster檢測鼠標點到了哪個3D物體，做點擊交互。

六、性能優化

面數太高掉幀。一個模型不要超過5萬面。

紋理太大佔顯存。壓縮到1024x1024。

像素比devicePixelRatio大於2時降採樣，手機GPU喫力。

七、常見坑

坑1：沒加光源，整個場景全黑。

坑2：相機位置不對，看不到物體。

坑3：模型面數太高，手機上卡成PPT。

八、總結

Three.js讓網頁3D普及。起步就是場景+相機+渲染器+幾何體+材質。性能注意面數和紋理。
