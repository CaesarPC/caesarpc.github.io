JavaScript深拷貝與淺拷貝（35）

CaesarTools 技術文章 · 2026-10-15

一、拷貝問題

對象賦值是引用，改一個另一個跟着變：

const a = { name: '小明' };

const b = a;

b.name = '小紅';

a.name也變成小紅。

二、淺拷貝

只拷一層：

const b = { ...a };

或Object.assign({}, a);

嵌套對象還是引用。改b.age.x，a.age.x也變。

三、深拷貝

拷所有嵌套：

const b = JSON.parse(JSON.stringify(a));

缺點：函數、undefined、Date丟失。

用lodash的_.cloneDeep最穩。

四、structuredClone

瀏覽器原生深拷貝：

const b = structuredClone(a);

五、常見坑

淺拷貝嵌套對象共享引用。

JSON.stringify丟函數和Date。

六、總結

淺拷貝用展開運算符，深拷貝用structuredClone或lodash。
