CSS響應式設計實戰（2）

首頁 / 文章教程 / CSS響應式設計實戰
CaesarTools 技術文章 · 2026-10-15

一、為什麼要響應式

你的網站在Mac上好好的，在手機上擠成一團。用戶從手機來的佔一半，不做響應式等於丟掉一半用戶。

二、移動優先

先寫手機樣式，再用min-width媒體查詢加桌面樣式。手機樣式是基礎，桌面是增強。

三、媒體查詢

@media (min-width: 768px) {

.container { grid-template-columns: repeat(2, 1fr); }

}

@media (min-width: 1200px) {

.container { grid-template-columns: repeat(4, 1fr); }

}

四、相對單位

用rem和%，不用px。字體1rem=16px（默認）。容器寬度用%或vw。

五、Grid自適應

grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));

容器多寬就自動排幾列，不用寫媒體查詢。

六、圖片響應式

手機下小圖，桌面下大圖。

七、常見斷點

手機<768px。平板768-1024px。桌面>1024px。大屏>1440px。

八、常見坑

媒體查詢寫反方向，從大到小要改寫法。

固定px寬度，小屏溢出。

字體用px，用戶改瀏覽器字體無效。

九、總結

響應式設計讓網站在手機、平板、桌面都好看。移動優先、相對單位、Grid自適應、圖片響應式。
