CSS變量與主題切換（56）

CaesarTools 技術文章 · 2026-10-15

一、CSS變量是什麼

CSS自定義屬性，像JS變量一樣複用值。

:root {

--primary-color: #4f46e5;

--spacing: 16px;

}

.button {

background: var(--primary-color);

padding: var(--spacing);

}

二、主題切換

黑暗模式：

:root[data-theme="dark"] {

--bg: #111;

--text: #fff;

}

切換主題改data-theme屬性，所有引用變量的地方自動變。

三、JS改變量

document.documentElement.style.setProperty('--primary-color', 'red');

四、常見坑

變量名大小寫敏感。

var第二參數是默認值：var(--color, black)。

IE不支持CSS變量。

五、總結

CSS變量讓樣式複用和主題切換簡單。換主題改根變量，全站跟着變。
