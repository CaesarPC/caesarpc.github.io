# 前端CSS預處理器：Sass與Less

原生CSS寫大項目很痛苦：沒有變量、沒有嵌套、沒有複用。CSS預處理器擴展了CSS的能力——變量、嵌套、混入、函數——編譯成普通CSS瀏覽器就能跑。Sass是最流行的預處理器。

## 一、變量

原生CSS沒有變量（雖然現在CSS變量已經普及了）。Sass： $primary-color: #3498db; .button { color: $primary-color; }

改主題色只改變量一處，全局生效。

## 二、嵌套

原生CSS選擇器一層層寫：.nav ul li a { }。Sass可以嵌套： .nav { ul { li { a { color: blue; } } } }

編譯後自動展開成完整選擇器。結構清晰，和HTML層級對應。

## 三、混入（Mixin）

複用一段樣式： @mixin flex-center { display: flex; justify-content: center; align-items: center; } .card { @include flex-center; }

## 四、現代趨勢

現在很多項目用CSS-in-JS（Styled Components）或CSS Modules替代預處理器。Tailwind CSS更是直接用原子化class，連預處理器都不太需要了。但Sass的思想——變量、嵌套、複用——影響了所有後來者。

## 五、總結

CSS預處理器解決了原生CSS的複用和組織問題。新項目可以根據團隊偏好選Sass或Tailwind，但理解預處理器的核心概念（變量、嵌套、混入），看任何樣式方案都不會陌生。
