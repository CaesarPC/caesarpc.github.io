JavaScript閉包實戰：數據私有化與函數工廠

閉包讓內部函數訪問外部函數的變量，即使外部函數已經執行完畢。這是因為JS的垃圾回收不會回收還被引用的變量。

典型用途：數據私有化。用閉包模擬私有變量，外部只能通過暴露的方法操作，不能直接修改。比如計數器：function counter() { let count = 0; return { inc: () => ++count, get: () => count }; }。外部拿到counter後，只能通過inc和get操作count，不能直接改。

函數工廠：用閉包生成特定功能的函數。比如創建多個帶前綴的日誌函數：function createLogger(prefix) { return (msg) => console.log(`[${prefix}] ${msg}`); }。每個logger有自己的prefix閉包。

防抖和節流也是閉包應用：用閉包保存定時器狀態。理解閉包，才能寫出模塊化、數據安全的JS代碼。
