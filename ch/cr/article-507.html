CSS佈局模式大全

CaesarTools 技術文章 · 2026-10-15

一、垂直居中的歷史

早年垂直居中是面試必考。方案：table-cell、絕對定位+margin:auto、負margin、transform。現在Flexbox三行代碼解決。

二、Flexbox居中

.container { display:flex; justify-content:center; align-items:center; }

Grid更簡潔：place-items:center一行。

三、三欄佈局

Flexbox：

.container { display:flex; }

.left { width:200px; }

.main { flex:1; }

.right { width:150px; }

Grid：

grid-template-columns:200px 1fr 150px。

四、等高分欄

Flexbox默認align-items:stretch，子元素等高。Grid同一行單元格等高。

五、sticky footer

body { display:flex; flex-direction:column; min-height:100vh; }

main { flex:1; }

內容不夠長footer貼底，內容長footer隨內容走。

六、後台佈局

Grid：

grid-template-areas:

"header header"

"sidebar main"

"footer footer";

七、響應式

移動優先：先寫手機，min-width媒體查詢增強。

Grid自適應卡片：repeat(auto-fill, minmax(220px,1fr))。

八、常見坑

float清除不乾淨。現代用Flex/Grid。

margin重疊。BFC隔離。

垂直居中用line-height，多行失效。

九、聖盃佈局和雙飛翼

早年float+負margin實現三欄。現在沒人用，面試可能問。知道歷史就行。

十、總結

CSS佈局從float hack演進到Flexbox一維、Grid二維。新項目Grid做骨架，Flex做組件。
