安裝 CaesarBase

選擇你的設備，裝成獨立 App

🍎 iOS / iPad

用 Safari 把 CaesarBase 添加到主屏幕，像獨立 App 一樣全屏運行。

1. 打開本頁用的瀏覽器必須是 Safari
2. 點底部中間的「分享」按鈕（⬆️ 方框箭頭）
3. 向下滑，點「添加到主屏幕」
4. 點右上角「添加」即可

🤖 鴻蒙 HarmonyOS

下載 APK 安裝包，安裝後是獨立 App。

⬇️ 下載 APK 安裝包

📱 安卓 Android

和鴻蒙用同一個 APK，安裝後是獨立 App。

⬇️ 下載 APK 安裝包

🪟 Windows

Windows 桌面版：解壓後雙擊 CaesarBase.exe 即可運行，帶專屬圖標。

⬇️ 下載 Windows 版 (zip)

鴻蒙/安卓安裝時若提示"未知來源應用"，請允許安裝。
