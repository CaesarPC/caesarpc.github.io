JavaScript模块导入导出

ES Module：export导出（命名导出、默认导出），import导入。命名导出要用花括号，默认导出不用。

命名导出：export const a = 1; import { a } from './mod'。 默认导出：export default function() {}; import anyName from './mod'。

一个模块只能有一个默认导出，但可以有多个命名导出。
