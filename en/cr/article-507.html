CSS布局模式大全

CaesarTools Tech Articles · 2026-10-15

一、垂直居中的历史

早年垂直居中是面试必考。方案：table-cell、绝对定位+margin:auto、负margin、transform。现在Flexbox三行代码解决。

二、Flexbox居中

.container { display:flex; justify-content:center; align-items:center; }

Grid更简洁：place-items:center一行。

三、三栏布局

Flexbox：

.container { display:flex; }

.left { width:200px; }

.main { flex:1; }

.right { width:150px; }

Grid：

grid-template-columns:200px 1fr 150px。

四、等高分栏

Flexbox默认align-items:stretch，子元素等高。Grid同一行单元格等高。

五、sticky footer

body { display:flex; flex-direction:column; min-height:100vh; }

main { flex:1; }

内容不够长footer贴底，内容长footer随内容走。

六、后台布局

Grid：

grid-template-areas:

"header header"

"sidebar main"

"footer footer";

七、响应式

移动优先：先写手机，min-width媒体查询增强。

Grid自适应卡片：repeat(auto-fill, minmax(220px,1fr))。

八、常见坑

float清除不干净。现代用Flex/Grid。

margin重叠。BFC隔离。

垂直居中用line-height，多行失效。

九、圣杯布局和双飞翼

早年float+负margin实现三栏。现在没人用，面试可能问。知道历史就行。

十、总结

CSS布局从float hack演进到Flexbox一维、Grid二维。新项目Grid做骨架，Flex做组件。
