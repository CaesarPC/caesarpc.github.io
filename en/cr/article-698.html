CSS变量与主题切换（56）

CaesarTools Tech Articles · 2026-10-15

一、CSS变量是什么

CSS自定义属性，像JS变量一样复用值。

:root {

--primary-color: #4f46e5;

--spacing: 16px;

}

.button {

background: var(--primary-color);

padding: var(--spacing);

}

二、主题切换

黑暗模式：

:root[data-theme="dark"] {

--bg: #111;

--text: #fff;

}

切换主题改data-theme属性，所有引用变量的地方自动变。

三、JS改变量

document.documentElement.style.setProperty('--primary-color', 'red');

四、常见坑

变量名大小写敏感。

var第二参数是默认值：var(--color, black)。

IE不支持CSS变量。

五、总结

CSS变量让样式复用和主题切换简单。换主题改根变量，全站跟着变。
