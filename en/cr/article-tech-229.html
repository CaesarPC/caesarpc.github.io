# 响应式设计：让一个页面适配所有屏幕

从手机到平板到桌面显示器，屏幕尺寸千差万别。你不可能为每种屏幕做一个独立版本——那维护成本太高了。响应式设计就是用一套代码，根据屏幕宽度自动调整布局和内容，在不同设备上都有良好的显示效果。

## 一、媒体查询

媒体查询是响应式的基础：根据屏幕宽度应用不同的CSS。

@media (max-width: 768px) { .container { flex-direction: column; } } 屏幕宽度小于768px时，容器变成垂直排列。

常见断点：手机<768px，平板768-1024px，桌面>1024px。在这些断点之间调整布局。

## 二、移动优先

现代响应式设计提倡移动优先：先写手机端的样式，再用min-width媒体查询逐步添加大屏样式。因为手机端布局最简单（一列排列），大屏更复杂（多列布局）。从简到繁比从繁到简容易。

## 三、弹性单位

不要用固定像素宽度。用百分比、vw/vh、rem这些弹性单位： - 百分比：相对于父元素宽度。 - vw/vh：相对于视口宽高（1vw = 视口宽度的1%）。 - rem：相对于根元素font-size。配合HTML font-size随屏幕宽度变化，整体缩放。

图片也要响应式：img { max-width: 100%; height: auto; }——图片永远不超过容器宽度。

## 四、Grid与自动响应

前面讲过Grid的auto-fit + minmax，一行代码实现自适应列数： grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); 屏幕宽就多列，窄就少列，自动换行。不需要写媒体查询。

## 五、总结

响应式设计不是高深技术，就是：弹性单位 + 媒体查询 + 移动优先。花时间写好断点和弹性布局，一个页面就能在手机和桌面上都好看。
