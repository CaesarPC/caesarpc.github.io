JavaScript解构赋值

解构赋值从数组或对象中提取数据，赋值给变量。数组解构：const [a, b] = [1, 2]。对象解构：const {name, age} = {name: 'Tom', age: 18}。

默认值：const [a=0, b=1] = []，a是0，b是1。对象解构重命名：const {name: userName} = {name: 'Tom'}，userName是'Tom'。

函数参数解构：function greet({name, age}) {}，直接传对象，参数里解构。这让函数参数更清晰。

解构让代码更简洁。不用const name = obj.name; const age = obj.age;直接const {name, age} = obj。
