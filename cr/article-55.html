JavaScript Promise完全指南

CaesarTools 技术文章 · 2026-10-15

一、为什么需要Promise

回调嵌套三层就是回调地狱。Promise把异步包成对象，链式调用，错误统一处理。

二、三种状态

pending进行中。fulfilled成功。rejected失败。状态不可逆。

三、基本用法

new Promise((resolve, reject) => {

setTimeout(() => resolve('ok'), 1000);

})

.then(data => console.log(data))

.catch(err => console.error(err))

.finally(() => console.log('结束'));

四、链式调用

fetchUser(1)

.then(user => fetchOrders(user.id))

.then(orders => render(orders))

.catch(err => showError(err));

纵向代码，可读。

五、四个静态方法

Promise.all全部成功才成功。

Promise.race谁快用谁。

Promise.allSettled等全部完成。

Promise.any取第一个成功。

六、async/await

async function load() {

try {

const user = await fetchUser(1);

const orders = await fetchOrders(user.id);

} catch (e) { showError(e); }

}

写起来像同步。

七、常见坑

await忘了加得到Promise对象。

串行await比并行慢，用Promise.all。

unhandledrejection没人catch，全局监听兜底。

八、Promise和事件循环

Promise.then是微任务，优先级高于setTimeout宏任务。

九、超时控制

Promise.race([fetchData, timeout(5000)])。防止请求无限等待。

十、总结

Promise是异步编程基石。async/await语法糖。掌握then/catch/finally和四个静态方法。
