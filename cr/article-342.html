Docker容器化部署实战

CaesarTools 技术文章 · 2026-10-15

一、Docker解决什么

开发Mac、测试Windows、生产Linux。环境不一致bug修不完。Docker把应用和依赖打包成镜像，任何机器跑起来一样。

二、Dockerfile

FROM node:20-alpine

WORKDIR /app

COPY package*.json ./

RUN npm ci --production

COPY . .

EXPOSE 3000

CMD ["node", "app.js"]

三、层缓存

先COPY package.json再npm ci。依赖没变就用缓存。

四、多阶段构建

前端构建产物不需要Node：

FROM node:20-alpine AS builder

COPY . .

RUN npm ci && npm run build

FROM nginx:alpine

COPY --from=builder /app/dist /usr/share/nginx/html

最终镜像50MB。

五、docker-compose

services:

api:

build: .

db:

image: postgres:16

docker-compose up -d。

六、生产要点

不要root跑容器。

镜像打版本标签。

日志输出stdout。

健康检查。

资源限制。

七、常见坑

容器监听127.0.0.1外部访问不到，要0.0.0.0。

容器重建数据丢，数据库挂volume。

镜像大，用alpine和多阶段。

八、CI/CD里用Docker

push代码→CI构建镜像→推到Registry→生产pull重启。全自动发布，环境一致。

九、总结

Docker是现代部署标配。写好Dockerfile、层缓存、多阶段、compose管理多服务。
