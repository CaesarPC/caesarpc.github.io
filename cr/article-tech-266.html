# 什么是JAMstack：前端现代架构

JAMstack = JavaScript + APIs + Markup。一种现代Web架构：前端是预渲染的静态HTML，动态数据通过API从后端获取。

## 一、核心思想

没有传统的Web服务器端渲染。网站构建时生成静态HTML/CSS/JS，部署到CDN上。需要动态数据时，前端JS调用API（数据库服务、第三方接口）获取。

## 二、好处

快：静态文件CDN分发，毫秒级加载。 安全：没有动态服务器被攻击的风险。 便宜：静态托管几乎免费。 扩展容易：CDN自动处理流量，不用管服务器。

## 三、代价

纯静态的限制：用户专属内容、实时数据需要走API。复杂的动态页面不如传统SSR灵活。

## 四、总结

JAMstack适合内容站、文档、营销页、工具站。静态文件+API，快且安全。复杂动态应用还是传统全栈更合适。
