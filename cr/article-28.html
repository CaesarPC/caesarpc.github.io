CSS布局模式大全：从圣杯到Grid的演进

CaesarTools 技术文章 · 2026-10-15 📅 2026-10-15

一、CSS布局为什么这么难

早年做个三栏布局，要float、清浮动、margin负值、hack。现在有Flexbox和Grid，几行代码搞定。但很多老代码还是float布局，新工程师看不懂。这篇梳理所有经典布局模式。

二、居中布局

2.1 Flexbox居中

.container { display:flex; justify-content:center; align-items:center; }

最简单的垂直水平居中。

2.2 Grid居中

.container { display:grid; place-items:center; }

更简洁，一行代码。

2.3 绝对定位+transform

.child { position:absolute; top:50%; left:50%; transform:translate(-50%,-50%); }

老浏览器兼容方案。

三、三栏布局

3.1 Flexbox三栏

.container { display:flex; }

.left { width:200px; }

.right { width:150px; }

.main { flex:1; }

左右固定，中间自适应。

3.2 Grid三栏

.container { display:grid; grid-template-columns:200px 1fr 150px; }

更直观。

3.3 圣杯布局

float + padding + 负margin的老方案。现在没人用了，面试可能问。

四、等高分栏

Flexbox默认align-items:stretch，子元素高度自动等高。不用额外处理。

Grid同理，同一行的单元格等高。

五、 sticky footer

内容不够长时footer贴底，内容长了footer随内容走。

Flexbox方案：body { display:flex; flex-direction:column; min-height:100vh; } main { flex:1; }

六、侧边栏+主内容

Grid方案：

.layout {

display:grid;

grid-template-columns:240px 1fr;

grid-template-rows:60px 1fr 40px;

grid-template-areas:

"header header"

"sidebar main"

"footer footer";

min-height:100vh;

}

后台管理系统标准布局。

七、响应式布局

7.1 移动优先

先写手机样式，再用min-width媒体查询增强。

@media (min-width:768px) { ... }

7.2 Grid自适应卡片

.card-list {

display:grid;

grid-template-columns:repeat(auto-fill, minmax(220px,1fr));

gap:20px;

}

不用写媒体查询，自动响应。

八、常见坑

坑1：float清除不干净。现代用Flex/Grid。

坑2：margin重叠。BFC隔离。

坑3：垂直居中用line-height。多行文字失效。

坑4：绝对定位元素撑开父容器。父容器要overflow:hidden。

九、垂直居中的历史

早年垂直居中是前端面试必考。方案：table-cell、绝对定位+margin:auto、负margin、transform。现在Flexbox三行代码解决。面试还问是因为老代码里还有这些hack。

十、总结

CSS布局从float hack演进到Flexbox一维、Grid二维。新项目无脑Grid做骨架、Flex做组件。老代码看到float不要慌，知道历史就行。
