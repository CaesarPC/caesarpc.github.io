JavaScript事件委托实战

事件委托利用事件冒泡，在父元素上绑一个监听器，处理所有子元素的事件。列表有100个按钮，不用每个都绑事件，在父元素上绑一个就行。

原理：事件冒泡到父元素，通过event.target判断实际点击的子元素。新增的子元素自动享受委托，不需要重新绑定。

优势：减少监听器数量（性能好）；动态添加的元素自动绑定；内存占用低。

实现：父元素.addEventListener('click', e => { if (e.target.matches('.item')) { ... } })。这是前端优化的常用技巧。
