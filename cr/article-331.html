Nginx反向代理实战

CaesarTools 技术文章 · 2026-10-15

一、Nginx是网站大门

用户访问先到Nginx。决定返回静态文件、转发Node、还是转发哪个实例。单机能抗5万并发。

二、静态站点

server {

root /var/www/dist;

location / { try_files $uri $uri/ /index.html; }

}

SPA路由刷新404，try_files fallback到index.html。

三、反向代理后端

location /api/ {

proxy_pass http://127.0.0.1:3000;

proxy_set_header Host $host;

proxy_set_header X-Real-IP $remote_addr;

}

四、负载均衡

upstream backend {

server 127.0.0.1:3000;

server 127.0.0.1:3001;

}

location / { proxy_pass http://backend; }

五、HTTPS

listen 443 ssl;

ssl_certificate /etc/letsencrypt/.../fullchain.pem;

80端口301跳HTTPS。

六、静态缓存

location ~* \.(js|css|png)$ {

expires 30d;

}

七、常见坑

WebSocket要Upgrade头。

大文件上传client_max_body_size调大。

改配置nginx -t测试再reload。

后端拿真实IP要X-Forwarded-For。

八、访问日志

默认在/var/log/nginx/access.log。记录每个请求的IP、路径、状态码、耗时。排查问题先看日志。

九、总结

Nginx做反向代理、负载均衡、HTTPS、静态缓存。学会基础配置网站才算上线。
