Redis缓存实战

CaesarTools 技术文章 · 2026-10-15 📅 2026-10-15

一、Redis是什么

数据放内存，读0.1毫秒。单线程，单机每秒10万读写。最常见用法是缓存热点数据。

二、基本用法

const redis = require('redis');

const client = redis.createClient();

await client.connect();

await client.setex('article:list', 10, JSON.stringify(articles));

const cached = await client.get('article:list');

三、缓存流程

先查缓存，没有查数据库，查完写回。

四、三大问题

穿透：查不存在的key。缓存空结果或布隆过滤器。

击穿：热点key过期。互斥锁或不过期。

雪崩：大量key同时过期。TTL加随机偏移。

五、更新策略

先更新数据库，再删缓存。不要先更新缓存。

六、其他用途

排行榜ZSet。分布式锁SET NX。消息队列List/Stream。

七、常见坑

大key拆分。

没TTL内存爆。

公网暴露开密码。

当数据库用，缓存要能从数据库重建。

八、生产部署

开密码、绑内网、RDB+AOF持久化、内存满allkeys-lru。主从+哨兵高可用。

九、缓存和数据库一致性

Cache-Aside模式：读时缓存miss再查库回写，写时先更新库再删缓存。极端情况有不一致窗口，要求高用延迟双删。

十、总结

Redis缓存热点数据抗压力。处理穿透、击穿、雪崩。生产开密码、持久化、主从高可用。
