JavaScript闭包完全指南：从原理到生产应用

CaesarTools 技术文章 · 2026-10-15

一、闭包是什么

function outer() {

let count = 0;

return function inner() {

count++;

console.log(count);

};

}

const fn = outer();

fn(); // 1

fn(); // 2

outer执行完了，count按理说该被回收。但fn还能访问它。这就是闭包：内部函数记住了外层作用域。

二、为什么需要闭包

JS早期没有模块系统，变量全挂全局。闭包提供私有变量：外面访问不到，内部通过方法操作。现代ES Module底层也是闭包。

三、实战场景

3.1 防抖节流

function debounce(fn, delay) {

let timer;

return (...args) => {

clearTimeout(timer);

timer = setTimeout(() => fn(...args), delay);

};

}

闭包保存timer状态。

3.2 函数工厂

function createLogger(prefix) {

return msg => console.log(`[${prefix}] ${msg}`);

}

每个logger有自己的prefix闭包。

3.3 数据私有化

const counter = (() => {

let count = 0;

return { inc: () => ++count, get: () => count };

})();

外部只能通过inc和get操作count。

四、经典坑：循环里的闭包

for (var i = 0; i < 3; i++) {

setTimeout(() => console.log(i), 1000);

}

输出3 3 3。var共享同一个i。

修法：用let块级作用域，或IIFE创建独立作用域。

五、内存泄漏

闭包持有外层变量，GC不能回收。事件监听器闭包持有DOM引用，DOM删了监听器没移除就泄漏。

解法：组件卸载时removeEventListener。

六、闭包和模块化

ES Module顶层变量不export就是私有。本质是模块函数的闭包。外部import只能用导出的方法，内部变量访问不到。现代模块化基于闭包。

七、总结

闭包让函数记住外层作用域。用途：私有变量、防抖节流、函数工厂、模块化。理解闭包是JS进阶关键。
