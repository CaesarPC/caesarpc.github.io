JavaScript深拷贝与浅拷贝

CaesarTools 技术文章 · 2026-10-15

一、拷贝问题

对象赋值是引用，改一个另一个跟着变：

const a = { name: '小明' };

const b = a;

b.name = '小红';

a.name也变成小红。

二、浅拷贝

只拷一层：

const b = { ...a };

或Object.assign({}, a);

嵌套对象还是引用。改b.age.x，a.age.x也变。

三、深拷贝

拷所有嵌套：

const b = JSON.parse(JSON.stringify(a));

缺点：函数、undefined、Date丢失。

用lodash的_.cloneDeep最稳。

四、structuredClone

浏览器原生深拷贝：

const b = structuredClone(a);

五、常见坑

浅拷贝嵌套对象共享引用。

JSON.stringify丢函数和Date。

六、总结

浅拷贝用展开运算符，深拷贝用structuredClone或lodash。
