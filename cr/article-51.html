浏览器存储：localStorage和IndexedDB

CaesarTools 技术文章 · 2026-10-15

一、浏览器能存什么

Cookie：4KB，每次请求自动带，适合存会话ID。

localStorage：5MB，永久存，只在前端读。

sessionStorage：标签页关闭就没。

IndexedDB：几百MB，结构化数据，异步API。

二、localStorage用法

localStorage.setItem('user', JSON.stringify(user));

const user = JSON.parse(localStorage.getItem('user'));

localStorage.removeItem('user');

同步API，存大数据会卡主线程。5MB够存用户设置。

三、IndexedDB

localStorage只能存字符串，5MB。IndexedDB能存结构化数据，几百MB，异步。

const db = await idb.openDB('myapp', 1, {

upgrade(db) {

db.createObjectStore('notes', { keyPath: 'id' });

}

});

await db.put('notes', { id: 1, text: '笔记内容' });

const note = await db.get('notes', 1);

四、什么时候用哪个

存用户设置、token：localStorage。

存大文件、大量笔记：IndexedDB。

存会话标识：Cookie。

五、常见坑

localStorage存JSON要stringify。

localStorage满了抛异常，要try catch。

隐私模式下localStorage不可用。

六、安全

localStorage里存敏感信息（密码、身份证），XSS攻击能偷到。重要信息用HttpOnly Cookie。

七、总结

浏览器存储选对工具。小数据localStorage，大数据IndexedDB，会话Cookie。
