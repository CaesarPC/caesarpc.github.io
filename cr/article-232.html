Node.js后端开发：从零写一个生产级API

CaesarTools 技术文章 · 2026-10-15

一、Node.js是什么

Chrome V8引擎套事件循环，让JS跑在服务器上。单线程非阻塞I/O。适合I/O密集：API服务、实时应用。CPU密集不适合。

二、最小服务

const http = require('http');

http.createServer((req, res) => res.end('Hello')).listen(3000);

三行代码一个服务。实际用Express。

三、Express入门

npm install express

const app = express();

app.use(express.json());

app.get('/api/users', (req, res) => {

res.json([{ id: 1, name: '小明' }]);

});

app.post('/api/users', (req, res) => {

res.status(201).json(req.body);

});

app.listen(3000);

四、路由拆分

routes/users.js：

const router = express.Router();

router.get('/', listUsers);

module.exports = router;

app.use('/api/users', require('./routes/users'));

五、错误处理

app.use((err, req, res, next) => {

res.status(500).json({ error: err.message });

});

六、连数据库

const { Pool } = require('pg');

const pool = new Pool({ connectionString: process.env.DATABASE_URL });

app.get('/api/users', async (req, res, next) => {

try {

const { rows } = await pool.query('SELECT * FROM users');

res.json(rows);

} catch (e) { next(e); }

});

参数化查询防注入。

七、JWT鉴权

function auth(req, res, next) {

const token = req.headers.authorization?.split(' ')[1];

try {

req.user = jwt.verify(token, process.env.JWT_SECRET);

next();

} catch { res.status(401).json({ error: '未登录' }); }

}

app.use('/api/protected', auth);

八、部署

PM2进程守护。Nginx反向代理。Docker打包。

九、常见坑

坑1：同步操作阻塞事件循环。CPU密集放Worker。

坑2：没处理unhandledRejection，进程崩。

坑3：CORS跨域。用cors中间件。

十、Node.js和其他后端

Node.js适合I/O密集、实时应用。Java适合大型企业系统。Python适合数据科学。Go适合高并发基础设施。选择看场景，不是选语言选信仰。

十一、总结

Node.js让前端工程师写后端API。Express是最稳框架。配合PostgreSQL、Redis、PM2、Nginx，一套完整后端栈。
