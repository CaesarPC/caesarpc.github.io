Nginx反向代理实战

CaesarTools 技术文章 · 2026-10-15

一、Nginx是网站大门

用户访问example.com，先到Nginx。Nginx决定：直接返回静态文件？转发给Node进程？转发给哪个Node实例？它单机能抗5万并发连接，而Node进程能处理几百个并发就不错了。学会Nginx是网站上线的最后一公里。

二、反向代理静态站点

server {

listen 80;

root /var/www/dist;

index index.html;

location / {

try_files $uri $uri/ /index.html;

}

}

SPA单页应用路由刷新404，try_files那行把所有请求fallback到index.html，让前端路由处理。这一行是React/Vue部署的关键。

三、反向代理后端API

location /api/ {

proxy_pass http://127.0.0.1:3000;

proxy_set_header Host $host;

proxy_set_header X-Real-IP $remote_addr;

proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

}

/proxy_set_header把真实IP和域名透传给后端，不然后端拿到的是Nginx的IP。

四、负载均衡多实例

upstream backend {

server 127.0.0.1:3000;

server 127.0.0.1:3001;

server 127.0.0.1:3002;

}

server {

location / {

proxy_pass http://backend;

}

}

三个Node实例轮询分发。一个挂了自动踢掉。配合PM2 cluster模式，充分利用多核CPU。

五、HTTPS配置

server {

listen 443 ssl;

ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;

ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

location / {

proxy_pass http://127.0.0.1:3000;

}

}

server {

listen 80;

return 301 https://$host$request_uri;

}

80端口301跳转到HTTPS。证书用Let's Encrypt免费签。

六、静态资源缓存

location ~* \.(js|css|png|jpg|woff2)$ {

expires 30d;

add_header Cache-Control "public";

}

静态资源浏览器缓存30天，不用重复下载。带hash文件名，更新自动刷新。

七、WebSocket支持

WebSocket需要Upgrade头：

location /ws/ {

proxy_pass http://127.0.0.1:8080;

proxy_http_version 1.1;

proxy_set_header Upgrade $http_upgrade;

proxy_set_header Connection "upgrade";

}

不配这个头，WebSocket握手直接失败。

八、常见坑

大文件上传client_max_body_size默认1MB，传个10MB文件报413。调大到50M。改配置必须nginx -t测试再reload，不然改错了整个网站挂。后端拿到的是Nginx IP，要配X-Forwarded-For透传。

九、访问日志

Nginx默认日志在/var/log/nginx/access.log。记录每个请求的IP、路径、状态码、耗时。排查问题先看日志。

十、总结

Nginx做反向代理、负载均衡、HTTPS终止、静态资源缓存。学会基础配置，网站才算真正上线。
