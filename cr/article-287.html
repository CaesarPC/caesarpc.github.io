JavaScript this指向完全指南

CaesarTools 技术文章 · 2026-10-15

一、this为什么难

同一个函数，调用方式不同，this不同：

function say() { console.log(this.name); }

const obj = { name: '小明', say };

obj.say(); // 小明

say(); // undefined

this在调用时确定，不是定义时。

二、四条规则按优先级

new绑定>显式绑定>隐式绑定>默认绑定。

三、逐个看

3.1 默认绑定

fn()单独调用，this是全局对象，严格模式undefined。

3.2 隐式绑定

obj.fn()，this是obj。

坑：赋值给变量再调用，this丢了。

3.3 显式绑定

fn.call(obj, arg)立刻执行。

fn.apply(obj, [args])参数是数组。

fn.bind(obj)返回新函数永久绑定。

3.4 new绑定

new Person()，this是新对象。

四、箭头函数

箭头函数没有自己的this，继承外层。回调函数用箭头函数，this不丢。

五、高频场景

回调this丢失用箭头函数或bind。

类里方法用箭头函数属性保持this。

六、常见坑

箭头函数当对象方法，this不是对象。

setTimeout里this不是你以为的。

七、判断this口诀

看函数怎么调用：new fn()新对象；fn.call(obj)是obj；obj.fn()是obj；fn()是全局。箭头函数继承外层。

八、总结

this看调用方式。记住四条优先级，箭头函数继承外层，this问题解决八九成。
