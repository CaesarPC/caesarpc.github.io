WebGL与Three.js 3D网页入门

CaesarTools 技术文章 · 2026-10-15 📅 2026-10-15

一、网页3D是什么

以前做3D网页要写OpenGL Shader，难倒一堆前端。Three.js把底层WebGL封装了，用JavaScript写3D网页变得像写HTML一样简单。现在产品展示、数据大屏、虚拟展厅、3D小游戏都能做。

三、核心概念

场景Scene：所有物体都放在里面。

相机Camera：决定从哪个角度看。

渲染器Renderer：把场景画到画布上。

几何体Geometry：物体的形状，盒子、球、圆柱。

材质Material：物体表面的颜色、反光。

光源Light：没有光就是黑的。环境光、平行光、点光源。

四、加载3D模型

设计师在Blender里做好模型，导出.glb文件：

import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loader = new GLTFLoader();

loader.load('model.glb', (gltf) => {

scene.add(gltf.scene);

});

五、交互

OrbitControls让鼠标拖动旋转视角：

import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const controls = new OrbitControls(camera, renderer.domElement);

Raycaster检测鼠标点到了哪个3D物体，做点击交互。

六、性能优化

面数太高掉帧。一个模型不要超过5万面。

纹理太大占显存。压缩到1024x1024。

像素比devicePixelRatio大于2时降采样，手机GPU吃力。

七、常见坑

坑1：没加光源，整个场景全黑。

坑2：相机位置不对，看不到物体。

坑3：模型面数太高，手机上卡成PPT。

八、总结

Three.js让网页3D普及。起步就是场景+相机+渲染器+几何体+材质。性能注意面数和纹理。
