Node.js部署：PM2进程管理

CaesarTools 技术文章 · 2026-10-15 📅 2026-10-15

一、Node进程的问题

node app.js直接跑，关终端进程死了。崩溃了不会自动重启。要多进程利用多核。

PM2解决这些。

二、PM2基础

npm install -g pm2

pm2 start app.js --name my-api

pm2 ls看进程。pm2 logs看日志。pm2 restart重启。

三、集群模式

pm2 start app.js -i max

自动开和CPU核数一样多的进程，一个挂了自动拉起。

四、开机自启

pm2 save

pm2 startup

服务器重启自动恢复。

五、日志

pm2 logs my-api。日志在~/.pm2/logs。切割轮转。

六、常见坑

直接node跑关终端死。用PM2。

单进程没用多核。开cluster。

日志不切割磁盘满。配logrotate。

七、环境变量

pm2 start app.js --env production。读process.env.NODE_ENV。

八、监控

PM2内置监控面板pm2 monit。看CPU、内存、请求数。更专业用Prometheus采集。

九、总结

PM2做进程守护、多进程、日志、开机自启。Node生产部署标配。
