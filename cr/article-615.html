HTTPS证书申请实战

CaesarTools 技术文章 · 2026-10-15

一、HTTPS为什么必须上

HTTP明文传输，密码被中间人看。2024年所有现代网站都上HTTPS。

二、Let's Encrypt免费证书

sudo certbot --nginx -d example.com -d www.example.com

Certbot自动申请证书、自动配置Nginx、自动续期。

三、证书有效期

Let's Encrypt证书90天有效期。Certbot自动续期，不用人管。

四、Nginx配置

server {

listen 443 ssl;

ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;

ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

}

五、HTTP跳转HTTPS

server {

listen 80;

return 301 https://$host$request_uri;

}

六、常见坑

域名解析要先配好。

80端口要开放。

证书要包含所有子域名。

七、总结

Let's Encrypt免费证书，Certbot一键配置。HTTPS是网站标配。
