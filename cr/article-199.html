CSS Grid完全指南：二维布局终极方案

CaesarTools 技术文章 · 2026-10-15

一、Grid和Flexbox的关系

Flexbox一维，处理一行或一列。Grid二维，同时控制行和列。后台骨架：左边栏右边内容，顶部底部固定，这种行列交叉布局用Grid最直观。

二、基本用法

.grid {

display: grid;

grid-template-columns: 200px 1fr 150px;

grid-template-rows: 60px 1fr 80px;

gap: 16px;

}

三列三行。fr分配剩余空间。

三、repeat和minmax

repeat(3, 1fr)三列等宽。

minmax(200px, 1fr)最小200px最大平分。

响应式卡片墙：

grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));

不用媒体查询自动换行。

四、命名区域

grid-template-areas:

"header header header"

"sidebar main main"

"footer footer footer";

改布局只改模板字符串，HTML不动。

五、子元素定位

grid-column: 1/3跨两列。

grid-row: 1/span 2跨两行。

六、对齐

justify-content整个网格对齐。

align-content垂直对齐。

justify-items单元格内容水平。

align-items单元格内容垂直。

七、常见坑

坑1：不写grid-template-rows，中间区不撑满。

坑2：图片溢出单元格。max-width:100%。

坑3：Grid做简单一行排列大材小用。用Flexbox。

八、auto-fill和auto-fit

auto-fill保留空轨道，auto-fit收缩空轨道。卡片数量少时auto-fit让少数卡片撑满，视觉更好。

九、总结

Grid二维布局。页面骨架用Grid，组件排列用Flexbox。两者配合是现代布局标配。
