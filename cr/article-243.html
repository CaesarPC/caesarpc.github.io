PostgreSQL实战：从建表到性能优化

CaesarTools 技术文章 · 2026-10-15

一、为什么选PostgreSQL

MySQL市占率高，PostgreSQL功能强。2024年新项目越来越多选PostgreSQL：JSONB、全文搜索、PostGIS、pgvector，一个数据库顶好几个。

二、建表规范

CREATE TABLE users (

id BIGSERIAL PRIMARY KEY,

email VARCHAR(255) UNIQUE NOT NULL,

name VARCHAR(100) NOT NULL,

created_at TIMESTAMPTZ DEFAULT NOW()

);

主键用BIGSERIAL。时间用TIMESTAMPTZ带时区。该加UNIQUE加UNIQUE。

三、索引

CREATE INDEX idx_users_email ON users(email);

WHERE、JOIN、ORDER BY字段加索引。小表不加。LIKE '%xx'用不到索引。

四、JSONB

CREATE TABLE posts (data JSONB);

SELECT * FROM posts WHERE data->>'title' = '第一篇';

GIN索引加速JSONB查询。

五、事务

BEGIN;

UPDATE accounts SET balance=balance-100 WHERE id=1;

UPDATE accounts SET balance=balance+100 WHERE id=2;

COMMIT;

转账必须事务。

六、连接池

const pool = new Pool({ max: 20 });

不要每次请求new Client。

七、备份

pg_dump dbname > backup.sql。每天定时。主从复制高可用。

八、常见坑

坑1：SELECT *。只查需要字段。

坑2：N+1查询。循环里查数据库。用JOIN。

坑3：忘了WHERE就UPDATE。先SELECT确认。

九、慢查询优化

EXPLAIN ANALYZE看执行计划。加缺失索引、SELECT只拿需要列、大表分页用WHERE id > last_id。

十、总结

PostgreSQL是通用数据库最优解。建表规范加索引、用好事务、连接池管理、定期备份。
