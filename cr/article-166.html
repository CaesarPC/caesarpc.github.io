JavaScript数组方法速查与实战

CaesarTools 技术文章 · 2026-10-15 📅 2026-10-15

一、为什么数组方法重要

数组是JS里最常用的数据结构。写业务就是处理数据：列表渲染、筛选、排序、统计。掌握数组方法，代码从for循环变成声明式，可读性翻倍。

二、遍历方法

2.1 map

map遍历返回新数组，每个元素加工一次。

const doubled = [1,2,3].map(x => x*2); // [2,4,6]

渲染列表：list.map(item =>

{item.name}
)。

2.2 forEach

遍历但不返回新数组。副作用操作用：

arr.forEach(item => console.log(item));

要返回值用map，不要用forEach硬凑。

三、筛选和查找

3.1 filter

过滤出符合条件的元素：

const adults = users.filter(u => u.age >= 18);

3.2 find

找第一个符合的元素，找不到返回undefined。

const user = users.find(u => u.id === 1);

3.3 some和every

some：有一个符合就true。

every：全部符合才true。

const hasAdmin = users.some(u => u.role === 'admin');

四、归约

reduce把数组归约成一个值：

const sum = [1,2,3].reduce((acc, x) => acc + x, 0); // 6

统计、分组、扁平化都能写。

五、判断和包含

includes：arr.includes(3)。

indexOf：找不到返回-1。

findIndex：找索引。

六、排序和反转

sort默认按字符串排数字要小心：

[1,10,2].sort((a,b) => a-b); // [1,2,10]

reverse反转。

七、变形

flat展平嵌套数组：[1,[2,[3]]].flat(2); // [1,2,3]

flatMap map后flat一层。

八、常见坑

坑1：map里写if不return，得到undefined。

坑2：sort没传比较函数，数字排序错。

坑3：for循环里异步，顺序乱。用for await。

九、链式调用

数组方法都返回新数组，可以链式：

const result = users

.filter(u => u.age >= 18)

.map(u => u.name)

.sort();

一行一行读，从左到右数据流。

十、总结

map加工、filter筛选、find查找、reduce归约、some/every判断。掌握这几个，数组业务代码90%搞定。
