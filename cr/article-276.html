JavaScript原型链完全指南：理解继承的底层机制

CaesarTools 技术文章 · 2026-10-15

一、JS为什么需要原型链

Java先写class再new对象。JS早期没有class，用对象之间直接关联实现继承。每个对象有个内部属性[[Prototype]]（浏览器里__proto__），指向它的原型。访问obj.prop时，obj自身没有，就顺着__proto__往上找，直到null。这条链就是原型链。

二、一个对象的原型链长什么样

const arr = [1,2,3];

arr.push(4);

arr对象上并没有push方法。arr.__proto__是Array.prototype，push就在那里。arr.__proto__.__proto__是Object.prototype，toString在那里。Object.prototype.__proto__是null，到头了。

三、constructor和prototype

每个函数有个prototype属性，这个对象有个constructor指回函数。

function Person(name) { this.name = name; }

Person.prototype.greet = function() { console.log(this.name); };

const p = new Person('小明');

p.__proto__ === Person.prototype;

p.constructor === Person;

new做了三件事：创建空对象、__proto__指向构造函数prototype、执行构造函数绑定this。

四、ES6 class是语法糖

class Person {

constructor(name) { this.name = name; }

greet() { console.log(this.name); }

}

底层和原型写法一样。extends实现继承，super调用父类。现代项目用class更易读，但要知道它是语法糖。

五、instanceof

obj instanceof Type：沿obj原型链找Type.prototype。

[] instanceof Array // true

[] instanceof Object // true

六、常见坑

坑1：for...in把原型链可枚举属性带出来。用hasOwnProperty过滤。

坑2：改prototype，所有实例立刻受影响。

坑3：__proto__不是标准API。用Object.getPrototypeOf()。

七、原型链查找性能

频繁访问深层原型属性有性能成本。热点方法应该在对象自身上，不要每次沿链找。V8引擎对常见原型链做了内联缓存优化，但写代码时还是要注意。

八、总结

原型链是JS继承根基。__proto__、prototype、constructor三者关系搞懂，class就是纸上谈兵。
