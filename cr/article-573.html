CSS Grid完全指南

CaesarTools 技术文章 · 2026-10-15

一、Grid和Flexbox关系

Flexbox一维，Grid二维。后台骨架行列交叉用Grid最直观。

二、基本用法

.grid {

display:grid;

grid-template-columns:200px 1fr 150px;

grid-template-rows:60px 1fr 80px;

gap:16px;

}

三列三行，fr分配剩余空间。

三、repeat和minmax

repeat(3, 1fr)三列等宽。

minmax(200px, 1fr)最小200px最大平分。

响应式卡片墙：repeat(auto-fill, minmax(220px,1fr))。

四、命名区域

grid-template-areas:

"header header header"

"sidebar main main"

"footer footer footer";

改布局只改模板。

五、子元素定位

grid-column:1/3跨两列。

grid-row:1/span 2跨两行。

六、对齐

justify-content整个网格对齐。

align-content垂直对齐。

justify-items单元格内容水平。

align-items单元格内容垂直。

七、常见坑

不写grid-template-rows中间不撑满。

图片溢出max-width:100%。

Grid做简单一行用Flexbox。

八、auto-fill和auto-fit

auto-fill保留空轨道。auto-fit收缩空轨道。卡片少用auto-fit撑满。

九、Grid和Flexbox怎么选

一行一列排列用Flexbox。行列交叉整体布局用Grid。实际配合：Grid做页面骨架，Flex做组件内部排列。

十、总结

Grid二维布局。页面骨架Grid，组件排列Flex。配合是现代标配。
