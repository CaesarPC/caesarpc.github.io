PostgreSQL实战指南

CaesarTools 技术文章 · 2026-10-15

一、为什么选PostgreSQL

MySQL市占率高，PostgreSQL功能强。2024年新项目多选PostgreSQL：JSONB、全文搜索、PostGIS、pgvector，一个顶好几个。

二、建表规范

CREATE TABLE users (

id BIGSERIAL PRIMARY KEY,

email VARCHAR(255) UNIQUE NOT NULL,

name VARCHAR(100) NOT NULL,

created_at TIMESTAMPTZ DEFAULT NOW()

);

主键BIGSERIAL。时间TIMESTAMPTZ带时区。该加UNIQUE加UNIQUE。

三、索引

CREATE INDEX idx_users_email ON users(email);

WHERE、JOIN、ORDER BY加索引。小表不加。LIKE '%xx'用不到。

四、JSONB

CREATE TABLE posts (data JSONB);

SELECT * FROM posts WHERE data->>'title' = '第一篇';

GIN索引加速。

五、事务

BEGIN;

UPDATE accounts SET balance=balance-100 WHERE id=1;

UPDATE accounts SET balance=balance+100 WHERE id=2;

COMMIT;

六、连接池

const pool = new Pool({ max: 20 });

不要每次请求new Client。

七、备份

pg_dump dbname > backup.sql。每天定时。主从复制高可用。

八、慢查询

EXPLAIN ANALYZE看执行计划。加索引、SELECT只拿需要列、大表分页用WHERE id > last_id。

九、常见坑

SELECT *只查需要字段。

N+1查询用JOIN。

忘了WHERE就UPDATE。

十、PostgreSQL扩展

PostGIS地理空间查询。pgvector向量检索做AI语义搜索。pg_trgm模糊搜索。一个数据库覆盖多种场景。

十一、总结

PostgreSQL是通用数据库最优解。建表规范加索引、用好事务、连接池、定期备份。
