WebSocket实时通信实战

CaesarTools 技术文章 · 2026-10-15

一、HTTP和WebSocket区别

HTTP请求响应，一次请求一次响应。服务器不能主动推数据。要做实时聊天，前端要每秒轮询一次，浪费。

WebSocket建立连接后一直保持，服务器可以主动推消息给前端。双向通信，实时聊天、实时股价、协同编辑都用它。

二、基本用法

// 前端

const ws = new WebSocket('wss://example.com/chat');

ws.onopen = () => ws.send('你好');

ws.onmessage = (e) => console.log('收到:', e.data);

// Node后端

const WebSocket = require('ws');

const server = new WebSocket.Server({ port: 8080 });

server.on('connection', (socket) => {

socket.on('message', (msg) => {

console.log('收到:', msg);

socket.send('已收到');

});

});

三、心跳保活

连接可能断。前端每30秒发ping，后端回pong。没收到pong就重连。

四、生产部署

Nginx反向代理WebSocket要配Upgrade头。

wss://加密，不能用ws://。

断开自动重连。

五、常见坑

WebSocket连接数限制，单机几万要扩容。

消息顺序保证。

不要传太大消息，分片。

六、什么时候用轮询

实时性要求不高，5秒更新一次够，用轮询简单。实时聊天用WebSocket。

七、总结

WebSocket是双向实时通信。聊天、股价、协同编辑。心跳保活、自动重连、Nginx配置Upgrade。
