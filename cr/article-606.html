Node.js后端开发

CaesarTools 技术文章 · 2026-10-15

一、Node.js是什么

V8引擎套事件循环，JS跑服务器。单线程非阻塞I/O。适合I/O密集API、实时应用。CPU密集不适合。

二、Express入门

const express = require('express');

const app = express();

app.use(express.json());

app.get('/api/users', (req, res) => {

res.json([{ id: 1, name: '小明' }]);

});

app.post('/api/users', (req, res) => {

res.status(201).json(req.body);

});

app.listen(3000);

三、路由拆分

routes/users.js：

const router = express.Router();

router.get('/', listUsers);

module.exports = router;

app.use('/api/users', require('./routes/users'));

四、错误处理

app.use((err, req, res, next) => {

res.status(500).json({ error: err.message });

});

五、连数据库

const { Pool } = require('pg');

const pool = new Pool({ connectionString: process.env.DATABASE_URL });

app.get('/api/users', async (req, res, next) => {

try {

const { rows } = await pool.query('SELECT * FROM users');

res.json(rows);

} catch (e) { next(e); }

});

参数化查询防注入。

六、JWT鉴权

function auth(req, res, next) {

const token = req.headers.authorization?.split(' ')[1];

try {

req.user = jwt.verify(token, process.env.JWT_SECRET);

next();

} catch { res.status(401).json({ error: '未登录' }); }

}

七、部署

PM2进程守护。Nginx反向代理。Docker打包。

八、常见坑

同步阻塞事件循环，CPU密集放Worker。

没处理unhandledRejection进程崩。

CORS用cors中间件。

九、Node和其他后端

Node适合I/O密集、实时应用。Java适合大型企业系统。Python适合数据科学。Go适合高并发基础设施。选择看场景。

十、总结

Node.js让前端工程师写后端API。Express+PostgreSQL+Redis+PM2+Nginx一套栈。
