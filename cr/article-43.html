CSS响应式设计实战

CaesarTools 技术文章 · 2026-10-15

一、为什么要响应式

你的网站在Mac上好好的，在手机上挤成一团。用户从手机来的占一半，不做响应式等于丢掉一半用户。

二、移动优先

先写手机样式，再用min-width媒体查询加桌面样式。手机样式是基础，桌面是增强。

三、媒体查询

@media (min-width: 768px) {

.container { grid-template-columns: repeat(2, 1fr); }

}

@media (min-width: 1200px) {

.container { grid-template-columns: repeat(4, 1fr); }

}

四、相对单位

用rem和%，不用px。字体1rem=16px（默认）。容器宽度用%或vw。

五、Grid自适应

grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));

容器多宽就自动排几列，不用写媒体查询。

六、图片响应式

手机下小图，桌面下大图。

七、常见断点

手机<768px。平板768-1024px。桌面>1024px。大屏>1440px。

八、常见坑

媒体查询写反方向，从大到小要改写法。

固定px宽度，小屏溢出。

字体用px，用户改浏览器字体无效。

九、总结

响应式设计让网站在手机、平板、桌面都好看。移动优先、相对单位、Grid自适应、图片响应式。
