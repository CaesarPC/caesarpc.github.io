TypeScript入门到实战

CaesarTools 技術文章 · 2026-10-15

一、JS的痛

动态类型运行时才发现错。大型项目改字段名编译不报错，用户点击才崩。TS加静态类型，编译时抓错。

二、基本类型

let name: string = '小明';

let age: number = 18;

let hobbies: string[] = ['篮球'];

三、接口

interface User {

id: number;

name: string;

email?: string;

readonly createdAt: Date;

}

传错字段编译报错。

四、联合类型

type Status = 'pending' | 'success' | 'error';

比string精确。

五、泛型

function identity(arg: T): T { return arg; }

写通用函数不丢类型。

六、React里用

interface Props { title: string; onClick: () => void; }

function Button({ title, onClick }: Props) { ... }

七、常见坑

any等于没写。开strict。

as强行断言出运行时错。

第三方库装@types/xxx。

八、类型推导

TS自动推导，不用每个都标注。边界（函数参数、公共API）标注就行。

九、Utility Types

Partial让所有属性可选。Pick选部分属性。Omit排除属性。ReturnType取函数Back类型。这些工具类型让类型操作更简洁。

十、总结

TS是JS加类型。大型项目编译期抓bug，重构有提示。新项目无脑TS。
