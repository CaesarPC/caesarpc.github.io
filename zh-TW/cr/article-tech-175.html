JavaScript闭包与作用域：理解函数背后的隐藏状态

闭包（Closure）是JavaScript的核心概念。函数可以"记住"它定义时的环境，即使在那个环境之外执行。这就是闭包：内部函数访问外部函数的变量，外部函数执行完后变量依然存活。

闭包的形成：内部函数引用了外部函数的变量，外部函数执行Back后，内部函数依然能访问那些变量。因为JS的垃圾回收不会回收还被引用的变量，所以这些变量"活"了下来。

常见用途：数据私有化。用闭包模拟私有变量，外部无法直接修改，只能通过暴露的方法操作。比如计数器：function counter() { let count = 0; return { increment: () => ++count, get: () => count }; }。外部拿到counter后，只能通过increment和get操作count，不能直接改。

循环中的闭包坑：for循环里用var声明变量，每个回调共享同一个变量，导致最终都是最后一个值。用let解决（块级作用域），或者用IIFE立即执行函数创建独立作用域。

闭包让JS拥有了函数式编程的能力：函数可以作为Back值、作为参数传递、记住环境。这是JS灵活强大的根源，也是面试高频考点。
