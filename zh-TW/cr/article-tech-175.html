JavaScript閉包與作用域：理解函數背後的隱藏狀態

閉包（Closure）是JavaScript的核心概念。函數可以"記住"它定義時的環境，即使在那個環境之外執行。這就是閉包：內部函數訪問外部函數的變量，外部函數執行完後變量依然存活。

閉包的形成：內部函數引用了外部函數的變量，外部函數執行返回後，內部函數依然能訪問那些變量。因為JS的垃圾回收不會回收還被引用的變量，所以這些變量"活"了下來。

常見用途：數據私有化。用閉包模擬私有變量，外部無法直接修改，只能通過暴露的方法操作。比如計數器：function counter() { let count = 0; return { increment: () => ++count, get: () => count }; }。外部拿到counter後，只能通過increment和get操作count，不能直接改。

循環中的閉包坑：for循環裡用var聲明變量，每個回調共享同一個變量，導致最終都是最後一個值。用let解決（塊級作用域），或者用IIFE立即執行函數創建獨立作用域。

閉包讓JS擁有了函數式編程的能力：函數可以作為返回值、作為參數傳遞、記住環境。這是JS靈活強大的根源，也是面試高頻考點。
