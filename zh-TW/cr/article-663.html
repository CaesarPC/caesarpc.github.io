Node.js进程管理PM2（52）

CaesarTools 技術文章 · 2026-10-15

一、为什么要PM2

node app.js，关终端进程就死了。PM2让进程后台运行，崩溃自动重启，开机自启。

二、基本用法

pm2 start app.js

pm2 list看进程。

pm2 logs app看日志。

pm2 restart app重启。

pm2 stop app停止。

三、集群模式

pm2 start app.js -i max

利用多核CPU，自动负载均衡。

四、开机自启

pm2 startup生成命令，执行后开机自动启动进程。

五、日志管理

pm2 logs --lines 100看最近100行。

日志自动轮转，不会越积越大。

六、常见坑

改代码后要pm2 restart。

环境变量要配ecosystem.config.js。

七、总结

PM2是Node生产必备。后台运行、崩溃重启、开机自启、集群模式。
