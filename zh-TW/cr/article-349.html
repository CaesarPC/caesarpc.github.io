MySQL索引实战（23）

CaesarTools 技術文章 · 2026-10-15

一、索引为什么快

没索引，查一条数据扫全表一百万行。有索引，B+树直接定位，查10行。

二、索引类型

主键索引：聚簇索引，叶子节点存整行数据。

普通索引：叶子节点存主键。

联合索引：多列联合，遵循最左前缀。

三、加索引

CREATE INDEX idx_name ON users(name);

四、什么时候加索引

WHERE条件、JOIN条件、ORDER BY、GROUP BY的列。

五、什么时候不加

小表不加。

频繁更新的列不加。

区分度低的列（性别）不加。

六、EXPLAIN看执行计划

EXPLAIN SELECT * FROM users WHERE name = '小明';

type列ALL是全表扫描，要优化。

key列看用了哪个索引。

七、常见坑

like '%xx'用不到索引。

函数包裹列用不到索引。

联合索引遵循最左前缀。

八、总结

索引让查询从全表扫变树查。加对索引，MySQL快十倍。
