# Docker Compose：多容器應用一鍵啟動

前面講過Docker單個容器，實際項目往往不止一個容器——你的應用需要數據庫、緩存、可能還有消息隊列。每個都手動docker run，參數一大堆，換臺服務器重新敲一遍。Docker Compose就是用一個配置文件定義所有服務，一條命令全部啟動。

## 一、docker-compose.yml

在項目根目錄建一個docker-compose.yml：

services: app: build: . ports: - "3000:3000" environment: - DATABASE_URL=mysql://db:3306/mydb depends_on: - db db: image: mysql:8 environment: - MYSQL_ROOT_PASSWORD=secret volumes: - dbdata:/var/lib/mysql redis: image: redis:alpine

一條docker compose up啟動三個服務。app、db、redis在同一個網絡裡，可以用服務名互相訪問——app連接mysql://db:3306，db就是數據庫容器的主機名。

## 二、數據卷

db下面的volumes把容器內的數據目錄映射到命名卷dbdata。容器刪了重建，數據還在。前面講過——不做數據卷，數據庫數據容器一刪就沒。

## 三、開發體驗

docker compose up啟動所有服務，docker compose down停止並刪除容器。改了代碼？app服務掛載了當前目錄進去，代碼改動實時生效。換臺電腦？裝了Docker，clone項目，docker compose up，一切跑起來。環境一致性徹底解決。

## 四、總結

Docker Compose是本地開發和小型部署的利器。一個yml文件定義整個應用的所有服務，一條命令啟動。個人項目用Compose完全夠了，不需要上K8s。
