# 什麼是ORM：對象關係映射

直接寫SQL操作數據庫很靈活，但字符串拼接容易出錯、表結構變了要改SQL。ORM（Object-Relational Mapping）讓你用面向對象的方式操作數據庫。

## 一、怎麼工作

定義一個User類對應數據庫的users表。要查用戶：User.find({ where: { id: 1 } })。要創建：User.create({ name: '張三' })。ORM自動生成SQL執行。

## 二、好處

不用寫原生SQL，用熟悉的API。 防SQL注入——ORM參數化查詢。 模型變更時統一管理。 類型安全（配合TypeScript）。

## 三、壞處

複雜查詢寫起來彆扭——ORM簡化了簡單CRUD，但複雜SQL（子查詢、特殊join）反而比手寫SQL難。 N+1查詢問題——查用戶列表再逐個查訂單，產生N+1次查詢。需要手動優化。

## 四、常見ORM

Prisma（現代TypeScript）、Sequelize、TypeORM（Node生態）。Django ORM（Python）。Hibernate（Java）。

## 五、總結

ORM讓數據庫操作變成面向對象。簡單CRUD用ORM效率高，複雜查詢還是手寫SQL。不是所有場景都要ORM，看項目需求。
