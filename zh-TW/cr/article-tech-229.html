# 響應式設計：讓一個頁面適配所有屏幕

從手機到平板到桌面顯示器，屏幕尺寸千差萬別。你不可能為每種屏幕做一個獨立版本——那維護成本太高了。響應式設計就是用一套代碼，根據屏幕寬度自動調整佈局和內容，在不同設備上都有良好的顯示效果。

## 一、媒體查詢

媒體查詢是響應式的基礎：根據屏幕寬度應用不同的CSS。

@media (max-width: 768px) { .container { flex-direction: column; } } 屏幕寬度小於768px時，容器變成垂直排列。

常見斷點：手機<768px，平板768-1024px，桌面>1024px。在這些斷點之間調整佈局。

## 二、移動優先

現代響應式設計提倡移動優先：先寫手機端的樣式，再用min-width媒體查詢逐步添加大屏樣式。因為手機端佈局最簡單（一列排列），大屏更復雜（多列布局）。從簡到繁比從繁到簡容易。

## 三、彈性單位

不要用固定像素寬度。用百分比、vw/vh、rem這些彈性單位： - 百分比：相對於父元素寬度。 - vw/vh：相對於視口寬高（1vw = 視口寬度的1%）。 - rem：相對於根元素font-size。配合HTML font-size隨屏幕寬度變化，整體縮放。

圖片也要響應式：img { max-width: 100%; height: auto; }——圖片永遠不超過容器寬度。

## 四、Grid與自動響應

前面講過Grid的auto-fit + minmax，一行代碼實現自適應列數： grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); 屏幕寬就多列，窄就少列，自動換行。不需要寫媒體查詢。

## 五、總結

響應式設計不是高深技術，就是：彈性單位 + 媒體查詢 + 移動優先。花時間寫好斷點和彈性佈局，一個頁面就能在手機和桌面上都好看。
