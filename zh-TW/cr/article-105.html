JavaScript防抖与节流

CaesarTools 技術文章 · 2026-10-15

一、为什么需要防抖节流

输入框每次按键都发请求，疯狂打后端。滚动事件每帧触发，主线程忙。防抖节流控制触发频率。

二、防抖debounce

等最后一次触发后再执行。输入框Search用：

function debounce(fn, delay) {

let timer;

return (...args) => {

clearTimeout(timer);

timer = setTimeout(() => fn(...args), delay);

};

}

const onSearch = debounce(search, 300);

三、节流throttle

固定时间间隔执行一次。滚动用：

function throttle(fn, interval) {

let last = 0;

return (...args) => {

const now = Date.now();

if (now - last >= interval) {

last = now;

fn(...args);

}

};

}

四、对比

防抖：停止输入后执行一次。

节流：每300毫秒执行一次。

五、常见场景

输入Search：防抖。

滚动加载：节流。

窗口resize：防抖。

六、总结

防抖节流控制事件频率。防抖等最后一次，节流固定间隔。
