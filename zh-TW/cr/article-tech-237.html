# SQL入門：增刪改查與聚合查詢

SQL是操作關係型數據庫的語言。不管你用MySQL、PostgreSQL還是SQLite，核心SQL語法幾乎一樣。掌握基本的增刪改查和聚合查詢，就能應對80%的日常數據庫操作需求。

## 一、查詢：SELECT

最基本的查詢：SELECT * FROM users——查users表所有列。但實際不要用*，指定需要的列更高效：SELECT id, name, email FROM users。

加條件：WHERE SELECT * FROM users WHERE age > 18 AND city = '北京'。

排序：ORDER BY created_at DESC DESC降序，ASC升序。

限制條數：LIMIT 10 OFFSET 20——分頁，取第3頁每頁10條。

## 二、插入：INSERT

INSERT INTO users (name, email, age) VALUES ('張三', 'zhangsan@example.com', 25);

一次插多條：INSERT INTO users (name, email) VALUES ('a', 'a@a.com'), ('b', 'b@b.com');。

## 三、更新：UPDATE

UPDATE users SET age = 26 WHERE id = 123;

警告：UPDATE不加WHERE會更新全表！執行前先SELECT確認條件對不對。

## 四、刪除：DELETE

DELETE FROM users WHERE id = 123;

同樣警告：不加WHERE刪全表。生產環境執行DELETE前先SELECT看看影響哪些行。

## 五、聚合查詢

COUNT(*)統計行數：SELECT COUNT(*) FROM users WHERE city = '北京';。

SUM/AVG/MAX/MIN：SELECT AVG(age) FROM users;。

GROUP BY分組：SELECT city, COUNT(*) FROM users GROUP BY city;——每個城市有多少用戶。

HAVING過濾分組：SELECT city, COUNT(*) c FROM users GROUP BY city HAVING c > 100;——只顯示用戶超過100的城市。

## 六、JOIN：多表關聯

訂單表有user_id，要查訂單和對應的用戶名： SELECT orders.id, users.name FROM orders JOIN users ON orders.user_id = users.id;

INNER JOIN只返回兩表匹配的行。LEFT JOIN保留左表所有行，右表沒匹配的填NULL。

## 七、總結

SQL的核心就這幾個動詞：SELECT查、INSERT增、UPDATE改、DELETE刪。加上WHERE條件、ORDER BY排序、LIMIT分頁、GROUP BY聚合、JOIN關聯——日常開發夠用了。複雜查詢先想清楚要什麼數據，再從這幾個積木組合。
